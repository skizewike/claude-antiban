# ClaudeBarrier Sentinel Android — Мобильный агент защиты для Android

Автономное мобильное приложение для защиты аккаунтов Claude на смартфонах и планшетах Android.

## Возможности

1. **Умный режим защиты (Smart Overlay):**
   - Плавающий виджет поверх всех окон (`SYSTEM_ALERT_WINDOW`), отображающий статус VPN в реальном времени прямо во время работы в официальном приложении Claude или браузере.
   - Зеленый статус — туннель активен, запросы шифруются, утечек нет.
   - Красный статус и виброоповещение — мгновенное предупреждение при обрыве VPN.
2. **Фоновый мониторинг (Foreground Service):**
   - Непрерывный контроль сетевых интерфейсов через системную службу Android.
   - Поддержка исключения из оптимизации энергопотребления (Doze Mode).
3. **Безопасный запуск:**
   - Прямой запуск официального клиента Claude или веб-версии claude.ai только при подтвержденном безопасном IP.

## Установка

1. Скопируйте файл `ClaudeBarrier-Android.apk` на ваше Android-устройство.
2. Разрешите установку из неизвестных источников и установите приложение.
3. При первом запуске нажмите кнопку «Включить» в секции «Показ поверх всех окон» и предоставьте разрешение системе.
4. Включите любой VPN-клиент (v2rayNG, Clash, WireGuard, OpenVPN, Amnezia) и работайте с Claude без риска геоблокировок.
