## 📱 Способ 1: Нативное мобильное приложение (`ProjectXO.apk`)

Установите готовый файл **`ProjectXO.apk`** на ваш Android смартфон:

### Возможности приложения:
1. **Векторная анимация 60 FPS на Canvas:**
   * **«PROTECTED»:** Плавно пульсирующий неоновый изумрудно-бирюзовый щит, вращающаяся звезда Anthropic ✶, радарные волны и защитные орбитальные частицы.
   * **«PROHIBITED»:** Мгновенная тревожная стробоскопическая анимация, красный знак запрета ⃠, виброотклик и блокировка при обрыве туннеля.
2. **Живая диагностика сети в реальном времени:**
   * Непрерывный опрос внешнего IPv4 через туннель (проверка на сервер Латвии `193.27.19.100` и блокировка при появлении IP РФ).
   * Проверка аппаратного состояния VPN на уровне системы (`NetworkCapabilities.TRANSPORT_VPN`).
   * Сокетный аудит доступности Cloudflare / Anthropic API (`api.anthropic.com:443`).
   * Аудит изоляции IPv6.
3. **Кнопки управления:**
   * **▶ ЗАПУСТИТЬ CLAUDE:** Безопасный запуск официального приложения Claude на Android или веб-интерфейса `claude.ai` в браузере.
   * **⚡ ТЕСТ СИМУЛЯЦИИ:** Безопасная проверка сброса сессии за 100 мс с вибрацией и демонстрацией тревожной анимации.
   * **🛡️ KILLSWITCH ЯДРА:** Переход в системные настройки VPN Android в 1 клик.
   * **⚙️ НАСТРОЙКИ:** Интерактивное окно настройки IP адреса VPN, интервала проверок и буфера упреждения.

## 🛡️ Способ 2: Встроенный аппаратный KillSwitch Android (Для приложения Claude)

На Android встроен самый надежный механизм предотвращения утечек на уровне ядра Linux:

1. Откройте **Настройки Android** $\rightarrow$ **Сеть и интернет** (или Подключения) $\rightarrow$ **VPN**.
2. Найдите ваше приложение VPN (**INCY**, **v2rayNG** или **Hiddify**) и нажмите на значок шестеренки (⚙️) рядом с ним.
3. Включите два тумблера:
   * **Постоянный VPN (Always-on VPN)**
   * **Блокировать соединения без VPN (Block connections without VPN)**
4. **Результат:** Android на уровне ядра системы запретит любым приложениям (включая Claude) отправлять хотя бы один байт данных мимо VPN. При обрыве связи интернет просто отключится, утечка реального IP невозможна на 100%.

## 💻 Способ 3: Сторож для Claude Code CLI в Termux (`xo_watchdog.sh`)

Если вы запускаете Claude Code CLI через Termux на Android:

1. Установите зависимости и скопируйте стража:
   ```bash
   ./install_termux.sh
   ```
   Или вручную:
   ```bash
   cp xo_watchdog.sh ~/
   chmod +x ~/xo_watchdog.sh
   ```
2. Запустите стража в отдельной вкладке Termux:
   ```bash
   ~/xo_watchdog.sh
   ```
3. Страж непрерывно мониторит туннель. При потере 3 пакетов подряд он моментально вызовет `pkill -9 claude`, выдаст вибрацию и спасет аккаунт от бана.
