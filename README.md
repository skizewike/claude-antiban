# Claude Anti-Ban Barrier (Project XO)

**Автор:** Bogdan Zhukov ([@bzhukov](https://t.me/bzhukov))  
**Версия:** 5.6.0  
**Платформы:** Windows 10/11 (WFP Ядро / .NET Framework / Cloudflare WARP Dark UI) + Android (Standalone APK)  
**Репозиторий:** [skizewike/claude-antiban](https://github.com/skizewike/claude-antiban)

Комплексный комплекс превентивной сетевой защиты и аппаратной изоляции для безопасной работы с сервисами Anthropic Claude (Claude Desktop, веб-интерфейс claude.ai и терминальный клиент Claude Code CLI) из регионов с ограниченным доступом.

---

## Архитектура и функционал в версии 5.6.0 (WARP Complete Redesign & Multi-Tier Guard Edition)

### 1. 1:1 Редизайн всех вкладок интерфейса в стиле Cloudflare One Client (WARP)
- **«Настройки» (Settings):**
  - Пользовательские переключатели `WarpToggleSwitch` (iOS/WARP style) без стандартных громоздких Windows CheckBox;
  - Сворачивание в трей, автозапуск с Windows, автостарт Zapret, аварийный KillSwitch;
  - Темные скругленные поля ввода и кнопки `Обзор...` для Claude Desktop, Claude Code CLI и Zapret winws;
  - Выделенная карточка полной деинсталляции и сброса сетевых правил в ядре Windows.
- **«Журнал» (Logs):**
  - Оформление в виде терминальной консоли ядра со светящимся индикатором реального времени `LIVE EVENT STREAM`;
  - Счетчик событий в верхнем баре консоли;
  - Фирменные кнопки WARP: `Очистить`, `Экспорт` (в файл `project_xo_export.log`), `Скопировать` (в буфер обмена).
- **«Обход блокировок» (Bypass):**
  - Интеграция службы Zapret DPI Bypass (winws.exe);
  - Настоящая кнопка **«Применить правила»** — реально внедряет правила фильтрации в Windows Firewall и реестр ОС;
  - Информационный блок **«Предупреждение о безопасности сети и разрыве VPN-туннеля»**.
- **«Подключение» (Connection):**
  - Статичные 3 карточки с нулевым скроллом (DNS-подключение, Tunnel со статусным бейджем, Безопасность и тесты).
  - Честный тест аварийного перехвата WFP (raw TCP SYN сокет к `160.79.104.10:443`).

### 2. Исправление накопления правил WFP (Баг с 30+ правилами)
- Устранено состояние гонки при быстром нажатии на правила: внедрен атомарный замок `Interlocked.CompareExchange(ref _isApplyingFirewallRules, 1, 0)`.
- Правила получили фиксированные детерминированные идентификаторы `-Name ('Claude-Shield-IPv4-' + $id)`.
- Перед внедрением выполняется полный сброс существующих правил по Name и DisplayName, исключая создание случайных дубликатов с разными GUID в реестре.

### 3. Новые уровни безопасности при разрыве VPN (KillSwitch)
- **Уровень 1 (Ядро WFP):** Блокировка подсетей `160.79.104.0/23` и `2607:6bc0::/32` на всех физических адаптерах (Wi-Fi/Ethernet).
- **Уровень 2 (Сторож процессов в User-Space):** Фоновый мониторинг сетевых маршрутов через `NetworkChange.NetworkAddressChanged` и высокочастотный таймер. При разрыве туннеля процессы Claude немедленно завершаются в памяти (< 15 мс) — **работает даже без прав Администратора!**
- **Уровень 3 (DNS-изоляция):** Отключение небезопасных механизмов Smart Multi-Homed Name Resolution и изоляция IPv6.

## Установка и запуск

### Вариант 1: Установщик (Рекомендуется)
1. Скачайте `Setup_Project_XO.exe` из раздела [Releases](https://github.com/skizewike/claude-antiban/releases).
2. Запустите файл от имени Администратора.
3. Программа автоматически развернет барьер, внедрит правила WFP ядра и создаст ярлыки.

### Вариант 2: Портативная версия (Portable)
1. Скачайте `ProjectXO.exe`.
2. Запустите от имени Администратора. Все компоненты и конфигурация сохраняются локально.

### Вариант 3: Android-приложение (ProjectXO.apk)
1. Скачайте `ProjectXO.apk` или архив `Project_XO_Android.zip`.
2. Установите на устройство Android. Приложение работает автономно без Termux или сторонних зависимостей.

## Сборка из исходного кода

```bat
cd project_xo
build.bat
```

Сборочный конвейер автоматически скомпилирует:
1. `Uninstall_Project_XO.exe` (Инструмент полной очистки системы);
2. `ProjectXO.exe` (Основное приложение защиты с интерфейсом WARP);
3. `Setup_Project_XO.exe` (Автономный дистрибутив со встроенной полезной нагрузкой);
4. `ProjectXO.apk` (Автономное Android-приложение, скомпилированное через AAPT2 и D8/ECJ);
5. `Project_XO_Android.zip` (Дистрибутив для Android).
