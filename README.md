# 🛡️ PROJECT XO // BOGDAN ZHUKOV — CLAUDE ZERO-LEAK GUARDIAN (v4.2 LUXURY EDITION)

![Project XO Banner](app_icon.png)

> **Абсолютная система аппаратной изоляции сетевого трафика Claude Desktop & CLI, предотвращающая блокировки аккаунтов Anthropic по геолокации (РФ / РБ).**  
> Включает Windows Filtering Platform (WFP), круглосуточную защиту в системном трее, зашифрованный Cloudflare DoH, интеграцию с Zapret DPI Bypass, интерактивный журнал событий, деинсталлятор полного отката и Android-компаньон с плавающим смарт-виджетом поверх всех окон.

## 🌟 Ключевые возможности версии v4.2

### 1. 👑 Премиальная прозрачная иконка (Zero White Borders)
- Полностью прозрачный альфа-канал `(0, 0, 0, 0)` во всех разрешениях: **16×16, 24×24, 32×32, 48×48, 64×64, 128×128, 256×256**.
- Никаких белых рамок или квадратов на рабочем столе. Каноничная 14-лепестковая терракотовая звезда Claude (`#D97757`) с обсидиановым ядром и монограммой **XO // BZ** (Bogdan Zhukov).
- Вшита во все исполняемые файлы (`ProjectXO.exe`, `Setup_Project_XO.exe`, `Uninstall_Project_XO.exe`), системный трей, ярлыки и APK для Android (`ic_launcher.png`).

### 2. 🛡️ Постоянная защита в системном трее (Tray Guard)
- Приложение невозможно случайно закрыть: нажатие кнопки `[X]` автоматически сворачивает программу в системный трей с всплывающим уведомлением.
- Защита ядра и сторожевой таймер работают непрерывно.
- Расширенное контекстное меню в трее:
  - 🟢 Быстрый просмотр статуса задержки и утечек (`ЗАЩИЩЕНО: 24 мс`).
  - 🚀 Безопасный запуск Claude в 1 клик.
  - 🔄 Обновление и аудит правил Брандмауэра WFP.
  - ⚙️ Автозагрузка с Windows (минимизированный запуск `--minimized`).
  - ❌ Полный выход с подтверждением.

### 3. ⚡ Комплекс обхода блокировок (Bypass & Anti-DPI Engine)
- **Cloudflare & Google DoH (DNS-over-HTTPS):** Прямое шифрованное разрешение `api.anthropic.com` и `claude.ai` через TLS 1.3 к `1.1.1.1` и `8.8.8.8`. Провайдер не видит домены и не может подменить IP.
- **Zapret DPI Bypass Integration:** Автоматическое обнаружение `winws.exe` на рабочем столе пользователя с готовыми пресетами обхода TCP 443 (`--wf-tcp=443 --dpi-desync=split2 --dpi-desync-split-pos=1 --dpi-desync-fooling=badseq`).
- **Preemptive WFP Barrier:** Физическая блокировка пула Anthropic ASN `160.79.104.0/23` на физических сетевых картах (Wi-Fi, Ethernet).

### 4. 📜 Интерактивный журнал событий (Live Diagnostic Logs)
- Встроенная консоль логов в реальном времени с миллисекундными таймстемпами.
- Цветовая дифференциация: `[SYS]`, `[WFP]`, `[CLOUDFLARE]`, `[DOH]`, `[SEC]`, `[KILLSWITCH]`.
- Кнопки: «Скопировать весь лог», «Очистить», «Открыть файл лога».
- Автоматическая ротация и запись в файл `project_xo.log`.

### 5. 🗑️ Автономный деинсталлятор (Uninstall_Project_XO.exe)
- Полный и безопасный откат всех внесенных изменений:
  - Удаление всех правил Брандмауэра `Claude-Shield-*`.
  - Восстановление привязки IPv6 (`ms_tcpip6`) на сетевых адаптерах.
  - Восстановление политики реестра `DisableSmartNameResolution`.
  - Удаление ярлыков на Рабочем столе и в меню Пуск.
  - Очистка записи в «Установка и удаление программ» Windows.

### 6. 📱 Android Smart Mode (Показ поверх всех окон)
- **Плавающий смарт-виджет (Floating Head):** Разрешение `SYSTEM_ALERT_WINDOW` позволяет индикатору защиты отображаться поверх любых окон (включая приложение Claude).
  - 🟢 Зеленый индикатор: туннель активен, Claude защищен.
  - 🚨 Красный индикатор + вибросигнал: мгновенное оповещение при обрыве VPN.
- **Фоновая служба (Foreground Service):** Непрерывный мониторинг состояния сети с постоянным уведомлением в шторке.
- **Исключение из энергосбережения:** Запрос `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`, исключающий усыпление фонового сторожа Android Doze mode.

## 🚀 Инструкция по установке и использованию

### Windows 10 / 11
1. **Быстрый запуск:** Запустите `ProjectXO.exe` с Рабочего стола.
2. **Полная установка в систему:** Запустите `Setup_Project_XO.exe` от имени администратора. Программа установится в `C:\Program Files\Project XO`, создаст ярлыки и пропишет деинсталлятор в Windows.
3. **Безопасная работа:** Нажмите большую зеленую кнопку **«🚀 ЗАПУСТИТЬ CLAUDE БЕЗОПАСНО»**.
4. **Сворачивание:** Нажатие на крестик `[X]` безопасно свернет программу в системный трей.

### Android
1. Установите **`ProjectXO.apk`**.
2. В приложении нажмите кнопку **«Включить»** в блоке «Показ поверх всех окон» и предоставьте системное разрешение.
3. Нажмите **«Настроить»** в блоке оптимизации батареи, чтобы система не останавливала фоновый мониторинг.
4. На экране появится плавающий аккуратный значок Claude, который следит за VPN в режиме реального времени!

## 🛠️ Сборка из исходников

Для автоматической пересборки всех компонентов выполните:

```cmd
build.bat
```

Скрипт компилирует C# модули через встроенный `csc.exe` (без внешних зависимостей) и собирает подписанный Android APK через AAPT2 и D8.
