# Claude Anti-Ban Barrier (Project XO)

**Автор:** Bogdan Zhukov ([@bzhukov](https://t.me/bzhukov))  
**Версия:** 5.4.0  
**Платформы:** Windows 10/11 (WFP Ядро / .NET Framework / Cloudflare WARP Dark UI) + Android (Standalone APK)  
**Репозиторий:** [skizewike/claude-antiban](https://github.com/skizewike/claude-antiban)

Комплексный комплекс превентивной сетевой защиты и аппаратной изоляции для безопасной работы с сервисами Anthropic Claude (Claude Desktop, веб-интерфейс claude.ai и терминальный клиент Claude Code CLI) из регионов с ограниченным доступом.

---

## Архитектура и функционал в версии 5.4.0 (Cloudflare WARP Edition)

### 1. 1:1 Интерфейс в стиле Cloudflare One Client (WARP)
- **Главный экран (Hero Dashboard):**
  - Центральный графический элемент: оригинальный `app_icon` крупного размера в окружении парящих гармонических частиц Cloudflare WARP с индикатором статуса соединения (✕ при отключении / ✓ при активной защите).
  - Крупный заголовок состояния сети: **«Отключено»** / **«Подключено»**.
  - Главная кнопка действия в фирменном стиле Cloudflare One: **«Подключить»** (насыщенный синий цвет `#2563eb`) / **«Отключить»**.
  - Селектор режима под кнопкой: `Режим: Трафик WFP + Cloudflare DoH (UDP/TCP) ▼`.
  - Строка быстрого запуска Claude: 3 аккуратные минималистичные карточки равной ширины (`Claude Desktop`, `Веб-версия claude.ai`, `Claude Code CLI`) с полным вертикальным разделением заголовка и светящейся точки статуса (полное устранение наложения текста и бейджей).
  - Фирменный футер `2026.8.2115.0 | © 2026 Bogdan Zhukov (@bzhukov)`.

### 2. Официальная иконографика (app_icon)
- Иконка в заголовке окна (Titlebar) и бренд-блок в верхнем углу сайдбара используют оригинальный векторный логотип Claude с знаком запрета (`app_icon.png`).
- Устранены процедурные оранжевые щиты.

### 3. Боковое меню и навигация WARP
- Вкладки в стиле плоских скругленных пилюль:
  - 🌐 **Главная** — главный экран защиты в стиле WARP;
  - 🕸 **Подключение** — сетевые шлюзы, HUD-панель телеметрии (5 чипов) и замер задержки;
  - ⚡ **Обход блокировок** — встроенная служба Zapret DPI Bypass (winws.exe);
  - ⚙ **Настройки** — пути к клиентам Claude, параметры запуска Zapret и деинсталлятор;
  - 📋 **Журнал** — системный лог событий в реальном времени.
- В левом нижнем углу сайдбара размещена кнопка обратной связи 💬, открывающая модальное окно прямого контакта с разработчиком **Bogdan Zhukov** ([@bzhukov](https://t.me/bzhukov)).

### 4. Встроенный модуль Zapret DPI Bypass (winws.exe)
- Полный комплект исполняемых файлов (`winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, `cygwin1.dll` и шаблоны пакетов) упакован в сборку `ProjectXO.exe` и распаковывается по требованию во внутренний каталог `tools/`.
- **По умолчанию выключен**, управление осуществляется через раздел «Обход блокировок» или опционально при включении барьера.

### 5. Честная сетевая телеметрия
- Многопоточный опрос независимых геораспределенных шлюзов (`ip-api.com`, `api.ipify.org`, `ipinfo.io`) для вычисления реального публичного IP и юрисдикции.
- Реальный замер задержки отклика (RTT/Ping) к боевому API Anthropic (`api.anthropic.com`).
- Проверка сетевых интерфейсов на утечки IPv6 и валидация системного DNS-кэша.

## Установка и запуск

### Вариант 1: Установщик (Рекомендуется)
1. Скачайте `Setup_Project_XO.exe` из раздела [Releases](https://github.com/skizewike/claude-antiban/releases).
2. Запустите файл от имени администратора. Мастер установит барьер в `C:\Program Files\Project XO`, настроит правила брандмауэра и создаст ярлыки.

### Вариант 2: Портативный запуск
1. Скачайте `ProjectXO.exe`.
2. Запустите от имени администратора.
