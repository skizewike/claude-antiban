## 🌟 О проекте / Overview

**Project XO** — это высокоточный комплекс безопасности, созданный для разработчиков и пользователей **Claude Desktop** (MSIX / WindowsApps) и **Claude Code** (CLI), предотвращающий блокировку аккаунтов со стороны Anthropic и Cloudflare при использовании VPN (INCY, v2rayNG, Hiddify, Sing-box).

Комплекс физически исключает утечку реального IP-адреса даже при внезапном обрыве связи за счет блокировки сетевых пакетов на уровне ядра Windows (Windows Filtering Platform) и превентивного сторожевого таймера.

## 🛡️ Устраненные векторы бана (Аудит безопасности)

| Вектор утечки | Почему Anthropic банит аккаунт | Как это решено в Project XO |
|---|---|---|
| **Cloudflare IPv6 Dual-Stack** | Серверы Anthropic имеют IPv6 `2607:6bc0::10`. Обычный VPN туннелирует только IPv4. Запросы летят напрямую провайдеру РФ по IPv6. | Ядро Брандмауэра Windows наглухо блокирует диапазон `2607:6bc0::/32` на всех физических интерфейсах (Wi-Fi, Ethernet). |
| **Микроразрыв в момент отправки** | При отправке запроса VPN подвисает на 1-2 секунды, Windows делает TCP Retry через Wi-Fi. Anthropic получает токен с IP РФ. | **Превентивный буфер на 3 секунды**: при первых потерях пакетов Claude уничтожается ДО падения туннеля. |
| **Smart Multi-Homed DNS (Win 10/11)** | Windows параллельно опрашивает DNS через домашний Wi-Fi и через VPN. | Project XO автоматически выключает `DisableSmartNameResolution` в системном реестре. |
| **Утечки UDP 443 (QUIC / HTTP/3)** | Браузеры и Electron умеют работать по протоколу QUIC поверх UDP. | Брандмауэр блокирует все типы протоколов (TCP + UDP) для Claude на физических адаптерах. |
| **Остаточный DNS-кэш провайдера** | В кэше сохраняются заглушки `0.0.0.0` от РКН. | Автоматическая очистка кэша DNS (`Clear-DnsClientCache`) перед каждой рабочей сессией. |

## ⚡ Возможности Project XO v4.1

1. **Аутентичная анимация Claude и векторная графика:**
   * **Режим «PROTECTED»:** Дышащий 14-лепестковый терракотовый лучистый астериск Claude (`#D97757`), мягкое радиальное свечение, расходящиеся импульсы и вращающиеся защитные частицы.
   * **Режим «PROHIBITED»:** Стробоскопический тревожный запрет (знак ⃠, перечеркнутая эмблема, красный стробоскоп и превентивный отстрел процессов).
   * **Динамическая телеметрия задержки:** Живой счетчик пинга в миллисекундах (`24 мс отклик • 0 мс утечки`) вместо статичного текста.
2. **Интерактивные развертываемые карточки диагностики (Accordion UI):**
   * Вместо непонятных консольных ошибок — 5 интерактивных карточек (IPv4, Брандмауэр ядра, Cloudflare TLS, IPv6/DNS, Политика приложений).
   * Каждая карточка кликабельна: разворачивает подробное описание риска, технические параметры и кнопку исправления прямо внутри карточки.
3. **Прозрачные окна процессов без скрытых консолей:**
   * При установке правил Брандмауэра и запуске стресс-теста выводится пошаговый визуальный лог с прогресс-баром (никаких внезапно исчезающих черных окон).
4. **Аппаратный Брандмауэр ядра (Zero-Leak):**
   * Динамическое определение сетевых карт (Wi-Fi, Ethernet) с созданием индивидуальных правил ядра Windows Filtering Platform.
   * Блокировка подсетей `160.79.104.0/23`, `2607:6bc0::/32` и пакета `Claude_pzs8sxrjxfjjc` при обрыве связи (0 мс задержки).
5. **Поддержка Android (APK v4.1 + Termux):**
   * **`ProjectXO.apk`** — мобильное приложение с аутентичной анимацией Claude, живым пингом и развертываемыми карточками диагностики.
   * Скрипт стража для Termux (`xo_watchdog.sh`).

## 🚀 Установка и запуск

### Вариант 1: Установщик Windows (Рекомендуется для ПК)
1. Скачайте `Setup_Project_XO.exe`.
2. Запустите от имени администратора.
3. Установщик скопирует файлы в `Program Files\Project XO`, создаст ярлыки на Рабочем столе и в меню Пуск, и автоматически активирует правила Брандмауэра.

### Вариант 2: Портативная версия для Windows (Portable)
1. Скачайте `ProjectXO.exe` и положите в удобное место.
2. Запустите и нажмите кнопку **«🛡️ БРАНДМАУЭР ЯДРА»** (1 раз).
3. Нажмите **«▶ ЗАПУСТИТЬ CLAUDE»** — начнется защищенная рабочая сессия.

### Вариант 3: Android Смартфон / Планшет (APK)
1. Установите файл **`ProjectXO.apk`** на ваш Android-телефон.
2. Откройте приложение: в нем работает живая анимация 60 FPS, проверка внешнего IP, сокетный аудит Anthropic и кнопка перехода в системный KillSwitch Android.
3. Нажмите кнопку **«🛡️ KILLSWITCH ЯДРА»** и активируйте тумблеры: **«Постоянный VPN»** и **«Блокировать соединения без VPN»**.
4. Запускайте Claude прямо из приложения кнопкой **«▶ ЗАПУСТИТЬ CLAUDE»**.

### Вариант 4: Claude Code CLI в Termux на Android
1. Скачайте архив `Project_XO_Android.zip`.
2. В Termux запустите `./install_termux.sh` и `./xo_watchdog.sh`.

## 🛠️ Сборка из исходников

Для компиляции всех платформ (Windows + Android) запустите:

```cmd
build.bat
```

Бинарные файлы создаются в директории `dist/`:
* `dist/ProjectXO.apk` (~19 KB, мобильное приложение Android)
* `dist/ProjectXO.exe` (~29 KB, автономный исполняемый файл Windows)
* `dist/Setup_Project_XO.exe` (~43 KB, установщик со встроенным ProjectXO.exe)
* `dist/Project_XO_Android.zip` (~25 KB, полный комплект для Android)
