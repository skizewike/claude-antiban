# Claude Anti-Ban Barrier (Project XO)

Разработчик: Bogdan Zhukov  
Версия: 5.0.0  
Архитектура: Windows (WFP / .NET WinForms) + Android (Standalone APK)

Инженерное решение для изоляции сетевого трафика и предотвращения блокировок учетных записей Anthropic Claude (Desktop, Web, Code CLI) по географическому признаку (РФ / РБ).

---

## Архитектура и принцип работы

### Причины блокировок учетных записей Claude
Anthropic применяет автоматические системы противодействия доступу из неподдерживаемых регионов. Блокировка аккаунта чаще всего происходит не во время штатной сессии через VPN, а вследствие кратковременных утечек трафика:
1. **Обрыв VPN-соединения в фоне:** При падении туннеля сетевой стек Windows автоматически перенаправляет пакеты через дефолтный физический шлюз (домашний роутер провайдера).
2. **Параллельные DNS-запросы (Smart Multi-Homed Name Resolution):** Windows параллельно опрашивает все настроенные DNS-серверы, включая DNS провайдера, что приводит к утечке посещаемых доменов и гео-определению по резолверу.
3. **Утечки по протоколу IPv6:** Если VPN-клиент не туннелирует IPv6, браузер или приложение обращаются к серверам Anthropic по нативному IPv6 провайдера РФ/РБ.
4. **Запуск до установления туннеля:** Случайное открытие Claude до активации VPN приводит к немедленной фиксации реального IP серверами Cloudflare.

### Механизм аппаратной защиты WFP (Windows Filtering Platform)
Project XO разворачивает превентивный барьер на уровне ядра Windows:
- **Физическая изоляция подсетей Anthropic:** Пул IP-адресов ASN Anthropic (`160.79.104.0/23` и `2607:6bc0::/32`), а также исполняемые файлы (`Claude.exe`, `claude.exe`, UWP-пакет `Claude_pzs8sxrjxfjjc`) принудительно блокируются на всех физических сетевых интерфейсах (Ethernet, Wi-Fi). Трафик разрешен исключительно через виртуальные адаптеры туннелей (`wintun`, `wireguard`, `tap`, `tun`).
- **Отключение утечек IPv6:** Протокол IPv6 отключается на уровне привязки физических карт (`Disable-NetAdapterBinding -ComponentId ms_tcpip6`).
- **Блокировка Smart Name Resolution:** В реестре Windows активируется политика `DisableSmartNameResolution = 1`, предотвращающая отправку запросов на DNS-серверы провайдера.
- **Интегрированный DNS-over-HTTPS (DoH):** Все обращения к доменам `claude.ai` и `api.anthropic.com` разрешаются через шифрованный канал DoH (Cloudflare `1.1.1.1` / Google `8.8.8.8`) по TLS 1.3, исключая перехват провайдером.

## Возможности системы

### 1. Превентивная блокировка запуска
Приложение непрерывно контролирует внешний сетевой адрес и статус туннеля. При обнаружении IP-адреса РФ/РБ или отсутствии VPN-адаптера доступ ко всем точкам входа Claude мгновенно блокируется:
- Кнопки интерфейса переводятся в защитный статус `[Заблокировано]`.
- При попытке запуска отображается системное предупреждение с пошаговой инструкцией по безопасному подключению.
- Запуск возможен только после подтверждения чистого зарубежного шлюза.

### 2. Три раздельных режима запуска
- **Claude Desktop:** Запуск официального настольного клиента `Claude.exe` (путь определяется автоматически или задается в конфигурации).
- **Claude в браузере:** Безопасный переход к `https://claude.ai` в системном веб-обозревателе.
- **Claude Code (CLI):** Запуск консольного окружения разработчика (`claude` / `npx @anthropic-ai/claude-code`) с преднастроенными переменными окружения.

### 3. Отсутствие фоновых консольных окон
Взаимодействие с процессами и проверка правил брандмауэра осуществляются напрямую через Win32 API и системный реестр без вызова утилит `taskkill.exe`, `ping.exe` или интерактивных окон PowerShell. Это устраняет мерцание экрана и паразитные всплывающие черные окна.

### 4. Автономный режим в системном трее
При закрытии главного окна приложение сворачивается в системный трей, сохраняя непрерывный мониторинг состояния сети и актуальность правил фильтрации. Контекстное меню трея отображает текущую задержку, статус шлюза и предоставляет доступ к безопасному запуску в один клик.

### 5. Полноценный деинсталлятор
Модуль `Uninstall_Project_XO.exe` обеспечивает чистый откат системы:
- Удаление всех правил `Claude-Shield-*` из Брандмауэра Windows.
- Восстановление привязки IPv6 на сетевых адаптерах.
- Сброс политики `DisableSmartNameResolution`.
- Удаление ярлыков и записей в реестре Windows.

## Android-компаньон (ProjectXO.apk)

Автономное приложение для платформы Android (не требует Termux, Root или сторонних скриптов):
- **Плавающий смарт-индикатор (System Alert Window):** Отображает текущий статус туннеля поверх всех окон поверх официального приложения Claude.
- **Фоновый мониторинг (Foreground Service):** Контролирует активный сетевой маршрут с отображением в системной панели уведомлений.
- **Защита от энергосбережения:** Поддержка исключения из оптимизации батареи (Doze mode) для круглосуточного отслеживания обрывов VPN.

## Инструкция по установке и настройке

### Развертывание на Windows 10 / 11
1. **Автоматическая установка:**  
   Запустите `Setup_Project_XO.exe` от имени администратора. Программа установится в `C:\Program Files\Project XO`, создаст ярлыки на рабочем столе и в меню «Пуск», а также зарегистрирует деинсталлятор в системе.
2. **Портативный режим:**  
   Запустите `ProjectXO.exe` напрямую. При необходимости программа запросит повышение привилегий для доступа к WFP.
3. **Эксплуатация:**  
   - Запустите ваш VPN-клиент (Clash, Nekoray, v2RayTun, Amnezia и др.) и подключите профиль.
   - Нажмите «Проверить соединение» в интерфейсе Project XO.
   - После подтверждения статуса «Защищено» используйте нужную кнопку запуска (Desktop, Браузер или Code CLI).

### Развертывание на Android
1. Скопируйте и установите файл `ProjectXO.apk`.
2. При первом запуске предоставьте разрешение «Показ поверх других приложений» для активации смарт-индикатора.
3. Разрешите работу в фоновом режиме без оптимизации аккумулятора.
4. Значок поверх экрана будет отображать статус соединения в процессе работы с Claude.

## Сборка из исходного кода

Проект собирается без внешних пакетных менеджеров стандартными средствами системы:

```cmd
build.bat
```

Пайплайн включает:
- Компиляцию C# модулей компилятором `csc.exe` (.NET Framework 4.0+).
- Сборку Android APK с использованием `aapt2`, `javac`, `d8` (R8) и подпись тестовым ключом.
- Упаковку релизных архивов.
