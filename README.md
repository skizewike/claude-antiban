# Claude Anti-Ban Barrier (Project XO)

**Автор:** Bogdan Zhukov ([@bzhukov](https://t.me/bzhukov))  
**Версия:** 5.5.0  
**Платформы:** Windows 10/11 (WFP Ядро / .NET Framework / Cloudflare WARP Dark UI) + Android (Standalone APK)  
**Репозиторий:** [skizewike/claude-antiban](https://github.com/skizewike/claude-antiban)

Комплексный комплекс превентивной сетевой защиты и аппаратной изоляции для безопасной работы с сервисами Anthropic Claude (Claude Desktop, веб-интерфейс claude.ai и терминальный клиент Claude Code CLI) из регионов с ограниченным доступом.

---

## Архитектура и функционал в версии 5.5.0 (Cloudflare WARP Connection & True Audit Edition)

### 1. 1:1 Редизайн вкладки «Подключение» в стиле Cloudflare One (WARP)
- **Полное устранение белых полос прокрутки:** верстка переработана на 3 статичные сгруппированные карточки, идеально помещающиеся в рабочую область без переполнения контейнера.
- **Секция 1: DNS-подключение:**
  - Протокол: `Cloudflare 1.1.1.1 (DNS-over-HTTPS)`.
  - Фирменная кнопка WARP: `Тест DoH` (отправка боевого запроса к HTTPS-резолверу 1.1.1.1 с замером задержки в мс).
- **Секция 2: Подключение Tunnel:**
  - Разделители строк 1px `#1c2130`.
  - Строка 1: `Статус подключения` со скругленным статусным бейджем-пилюлей (`Подключено` / `Отключено`).
  - Строка 2: `Внешний IP и страна` (честный IP и геолокация по независимому пулу гео-шлюзов).
  - Строка 3: `Шлюз Anthropic (api.anthropic.com)` (замер реального TLS-пинга или блокировки провайдером).
  - Строка 4: `Брандмауэр ядра WFP (Windows Filtering Platform)` (индикация активных аппаратных правил изоляции).
- **Секция 3: Безопасность и тесты:**
  - Строка 1: `Аварийный перехват WFP` + кнопка `Тест перехвата` (настоящий сокет-тест ядра ОС).
  - Строка 2: `Диагностика сетевого шлюза` + кнопка `Проверить соединение` (запуск многопоточного аудита).

### 2. Честный аварийный перехват WFP (100% реальные измерения)
- Никаких фиктивных имитаций или выдуманных таймингов: приложение отправляет низкоуровневый TCP SYN пакет к боевому IP-диапазону Anthropic (`160.79.104.10:443`).
- Замер точного времени реакции драйвера фильтрации Windows Filtering Platform через высокоточный `Stopwatch`.
- Перехват и расшифровка системных кодов сетевого сокета ОС:
  - `10013 (WSAEACCES)` — немедленный аппаратный сброс пакета драйвером WFP на уровне ядра Windows;
  - `10065 (WSAEHOSTUNREACH)` / `10051 (WSAENETUNREACH)` — маршрутная изоляция пакета.
- Прямое чтение зарегистрированных правил изоляции из системного реестра Windows (`SharedAccess\Parameters\FirewallPolicy\FirewallRules`).

### 3. Главный экран (Hero Dashboard) в стиле Cloudflare One Client
- Центральный графический элемент: оригинальный `app_icon` крупного размера в окружении парящих гармонических частиц Cloudflare WARP с индикатором статуса соединения (✕ при отключении / ✓ при активной защите).
- Крупный заголовок состояния сети: **«Отключено»** / **«Подключено»**.
- Главная кнопка действия в фирменном стиле Cloudflare One: **«Подключить»** (насыщенный синий цвет `#2563eb`) / **«Отключить»**.
- Селектор режима: `Режим: Трафик WFP + Cloudflare DoH (UDP/TCP) ▼`.
- Строка быстрого запуска Claude: 3 минималистичные карточки равной ширины (`Claude Desktop`, `Веб-версия claude.ai`, `Claude Code CLI`) с полным вертикальным разделением заголовка и светящейся точки статуса.
- Фирменный футер `2026.8.2115.0 | © 2026 Bogdan Zhukov (@bzhukov)`.

### 4. Встроенный модуль Zapret DPI Bypass (winws.exe)
- Полный комплект исполняемых файлов (`winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, `cygwin1.dll` и шаблоны пакетов) упакован в сборку `ProjectXO.exe` и распаковывается по требованию во внутренний каталог `tools/`.
- **По умолчанию выключен**, управление осуществляется через раздел «Обход блокировок» или опционально при включении барьера.

## Установка и запуск

### Вариант 1: Установщик (Рекомендуется)
1. Скачайте `Setup_Project_XO.exe` из раздела [Releases](https://github.com/skizewike/claude-antiban/releases).
2. Запустите файл от имени Администратора.
3. Программа автоматически развернет барьер, внедрит правила WFP ядра и создаст ярлыки.

### Вариант 2: Портативная версия (Portable)
1. Скачайте `ProjectXO.exe`.
2. Запустите от имени Администратора. Все компоненты и конфигурация сохраняются локально.

### Вариант 3: Android-приложение (ProjectXO.apk)
1. Скачайте `ProjectXO.apk` или архив `Project_XO_Android.zip`.
2. Установите на устройство Android. Приложение работает автономно без Termux или сторонних зависимостей.

## Сборка из исходного кода

```bat
cd project_xo
build.bat
```

Сборочный конвейер автоматически скомпилирует:
1. `Uninstall_Project_XO.exe` (Инструмент полной очистки системы);
2. `ProjectXO.exe` (Основное приложение защиты с интерфейсом WARP);
3. `Setup_Project_XO.exe` (Автономный дистрибутив со встроенной полезной нагрузкой);
4. `ProjectXO.apk` (Автономное Android-приложение, скомпилированное через AAPT2 и D8/ECJ);
5. `Project_XO_Android.zip` (Дистрибутив для Android).
